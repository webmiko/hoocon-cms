## 1. Цель продукта

Сделать управляемый B2B-сайт и CMS для Hoocon (HVAC / электроприводы ОВК):

каталог с фильтрами, карточки SKU с ТТХ и файлами, глобальный поиск,
контент (статьи, новости, страницы), заявки вместо корзины. Заменить
ограничения Tilda ([hoocon.ru](https://hoocon.ru)) на свой стек.

Заказчик/пользователь получает: быстрый подбор продукции, документы,
заявку на КП; менеджер — админку каталога и контента.

## 2. Границы (scope)

### Входит в v1 (MVP)

- Каталог: категории, продукты, SKU, атрибуты, файлы (PDF).
- Фильтры и сортировка; URL отражает фильтры.
- Глобальный поиск по каталогу и статьям (Postgres FTS).
- CMS-страницы, новости, статьи.
- Формы: запрос КП, консультация, «подобрать замену».
- Публичный фронт (React) + SEO гибрид; админка staff.
- Импорт начальных данных из `../hoocon/data/` (ETL-скрипт).
- Docker Compose для local; базовая CI (lint, test) на GitHub.
- Цены в БД; **по умолчанию скрыты** (только по запросу / в заявке);
  флаг настройки «показывать цены на сайте» без смены кода.
- Git: **приватный** GitHub-репозиторий; разработка локально,
  выкладка на prod — когда MVP готов.
- Prod: **VPS + домен + почта на reg.ru** (одна платформа); SMTP
  заявок через ящики reg.ru; см. [docs/infra-reg-ru.md](docs/infra-reg-ru.md).
- SEO: **сохранить ЧПУ** из текущего sitemap; для `/tproduct/…` и
  прочих старых path — **301** на канон; см.
  [docs/seo-url-migration.md](docs/seo-url-migration.md).

### Не входит в v1

- Онлайн-корзина и оплата.
- Личный кабинет дилера с остатками (цены в БД — да; витрина — по флагу).
- Полноценный BIM/CAD portal.
- Мультиязык EN (заложить i18n-поля `*_en` опционально с Iter 1 как задел).
- Meilisearch (этап 2). Wagtail не планируем, пока не решим иначе.
- Публичный показ цен **по умолчанию** (включается настройкой).
- `accounts` app (отдельные роли) — используем `django.contrib.auth` +
  `is_staff`; JWT/React-admin — только при появлении отдельной роли.

## 3. Критерий готовности MVP

Нумерация M1–M8 синхронна с [docs/plan-detail-mvp.md](docs/plan-detail-mvp.md) §3.

1. **M1** Каталог — **вся продукция** из текущего каталога Hoocon
   (ETL полный импорт; снимок 2026-07-19: **~39 SKU** в Tilda Store /
   `hoocon_catalog_api.json`); фильтры работают; поиск находит SKU
   и статью. `SKU.count ≥ store total`.
2. **M2** Карточка SKU: ТТХ, ≥1 PDF, CTA «Запросить КП» создаёт Lead в БД.
3. **M3** Статья и «О компании» редактируются staff без деплоя кода
   (slug `/statyi/…`, `/company`).
4. **M4** Lighthouse/smoke: базовый CWV (LCP < 2 s, INP < 200 ms,
   CLS < 0.08) и уникальные title на ключевых URL; head в исходном HTML.
5. **M5** pytest зелёный на домен каталога и leads; ruff/mypy в CI
   (GHA pipeline green).
6. **M6** Инвентарь URL: path из основного sitemap
   ([seo-url-migration.md](docs/seo-url-migration.md) §2.1) → **200**
   с тем же path; canonical совпадает.
7. **M7** Все `/tproduct/…` из карты → **301** на ЧПУ SKU
   (pytest `Redirect`; seed CSV залит).
8. **M8** SMTP Lead через ящик reg.ru (staging/prod): лог Celery +
   входящее письмо на `sales@hoocon.ru`.

## 4. Стек (кратко)

См. [docs/stack-decision.md](docs/stack-decision.md).

| Слой | Выбор |
|------|-------|
| Backend | Django + DRF + `drf-spectacular` (OpenAPI) |
| БД | PostgreSQL (FTS, JSONB для атрибутов SKU) |
| Очереди | Celery + Redis |
| Static/Media | `whitenoise` (static), локальный диск VPS (media) |
| WSGI | `gunicorn` |
| Frontend | React + TypeScript + Vite |
| Edge | nginx, Docker Compose |
| Поиск v1 | Postgres FTS → Meilisearch (этап 2) |
| CI | GitHub Actions (lint/test/build/deploy SSH) |

**Не в v1:** онлайн-корзина, Stripe/платежи, Next.js, Meilisearch, Wagtail.

## 7. Риски

| Риск | Митигация |
|------|-----------|
| Грязные данные Tilda/CSV | ETL validate + quarantine; ручной review;
  **не** копировать тексты/UX-ошибки as-is |
| SEO просадка при смене URL | **сохранить ЧПУ**; 301 для `/tproduct/` и дублей |
| Сменили slug «для красоты» | Запрет без Redirect; code review + CI тест на CSV |
| Query-фильтры в индексе | canonical на `/catalog`; `sitemap.xml` без query |
| Сложность атрибутов SKU | EAV или JSONB schema + индексы |
| Scope creep (корзина, дилеры) | жёсткий §2 |
| Утечка цен / PII / спам форм | Serializer + flag; маски логов; honeypot/throttle |
| Misconfig на VPS | DEBUG=False, check --deploy, CSP/TLS (security-baseline) |
| Docker Desktop не запущен | `USE_SQLITE=True` для локальной разработки без Postgres |
| Доставляемость почты reg.ru | SPF/DKIM/DMARC; не слать с «голого» IP без PTR |

Доп. SEO-риски — [plan-detail-mvp.md](docs/plan-detail-mvp.md) §«Риски SEO».
