1Как это работает

Новосистем работает на платформе UIS. Общий вход — 8 800 350-58-98: звонок сразу идёт Валерии, Александру и Ларисе, разговор забирает тот, кто ответил первым. Когда менеджер сам звонит клиенту из окна «Телефон» или из приложения UIS, клиент видит +7 (499) 995-12-77. Личный мобильный в дозвон не входит и клиенту не показывается.

Телефон в браузере. Схема выше — обычный звонок: кнопка «Позвонить клиенту» набирает номер в окне «Телефон», без программы «Софтфон UIS» и без первого звонка вам. Прежний способ, когда UIS сначала звонит вам в приложение, остаётся только у сотрудника без токена WebRTC — раздел 6.

NEW Виджет с выключателем

Все настройки Новосистем — в одной карточке на странице «Интеграции». Выключили виджет — CRM перестаёт звонить через UIS и принимать от него события.

NEW Звонок из карточки

Окно «Телефон» и кнопка «Позвонить клиенту» звонят через UIS. Если окна нет, CRM звонит через Новосистем по ID сотрудника UIS.

NEW Журнал звонков

UIS присылает уведомления о звонках, CRM пишет их в раздел «Звонки» и находит клиента по цифрам номера.

2Виджет в интеграциях

Настраивает администратор. Менеджеру этот раздел нужен, только чтобы понять, почему звонок не идёт.

  1. Откройте «Настройки сайта» → «Интеграции».Рабочая карточка — «Новосистем».
  2. В карточке «Новосистем» включите переключатель.Подпись сразу меняется: «Виджет выключен», «Не полностью» или «Виджет включён».
  3. «Ключ API» — постоянный ключ пользователя UIS с доступом к Call API.Как его получить — раздел 3.
  4. «Виртуальный номер» — 74999951277, это +7 (499) 995-12-77.Его клиент видит при звонке из окна «Телефон» и из приложения UIS.
  5. «Секрет вебхука» — любая длинная случайная строка, которую вы придумали сами.По ней CRM понимает, что уведомление пришло от вашего кабинета UIS.
  6. Нажмите «Сохранить».Под полями появится «URL для ЛК UIS» — он уже содержит ?token= с вашим секретом. Его вставляют в уведомления UIS.
Статус на карточкеЧто значит
«Подключён»Виджет включён, заполнены ключ, виртуальный номер и секрет
«Не полностью»Виджет включён, но какого-то поля не хватает
«Выключен»Галочка снята: звонки через UIS и приём событий отключены
Пустое поле не стирает ключ. После сохранения ключ и секрет не показываются: в поле стоят точки, как у введённого пароля. Чтобы сменить, введите новое значение. Оставили точки или стёрли поле — остаётся старое.

3Настройка личного кабинета UIS

Делается один раз, в кабинете Новосистем (UIS) с правами администратора.

  1. Опция API уже стоит: «Базовые отраслевые решения».«Администратор → Аккаунт → Тариф и опции». Она даёт журнал звонков и звонок из карточки. «API Базовый» дешевле, но звонка из карточки в нём нет.
  2. Добавьте IP сервера CRM в белый список.«Аккаунт → Правила и настройки безопасности → API». Пока список пуст, UIS отклоняет запросы CRM. IP сервера даёт администратор хостинга.
  3. Выпустите ключ.«Управление пользователями» → пользователь → галочки «Доступ по ключу» и «Доступ к Call API». Ключ показывается один раз — сразу вставьте его в «Ключ API» виджета.
  4. Создайте HTTP-уведомление.«Сервисы и статистика → Уведомления» (в новом кабинете — «Интеграции»). Метод POST, адрес — «URL для ЛК UIS» из виджета целиком, вместе с ?token=….
  5. Добавьте параметры в тело уведомления.Кнопкой «Добавить параметр», имена — ровно как в таблице ниже.
ПараметрЗачем CRM
call_session_idОбязателен. Один звонок — одна строка в журнале, повторы обновляют её
directionВходящий или исходящий (in / out)

Без call_session_id событие отклоняется. Без верного token или при выключенном виджете — тоже. Журнал отправок в UIS: «Отчёты → Служебные». Если CRM не ответила, UIS повторит отправку через 2, 4, 8 и 16 часов.

4Сотрудник: ID UIS и добавочный

Чтобы кнопка звонка знала, кому звонить первым, у менеджера в CRM должен быть указан его ID сотрудника в UIS.

  1. Узнайте ID сотрудника в ЛК UIS.«Управление пользователями» / «Сотрудники» → карточка сотрудника, числовой идентификатор.
  2. Откройте пользователя в CRM: «Пользователи» → нужный менеджер.Внизу страницы — блок «Телефония сотрудника».
  3. Заполните «ID сотрудника UIS».Только цифры.
  4. «Добавочный» — внутренний номер, если UIS присылает его в уведомлении.Короткий добавочный в звонок из карточки не подставляется: UIS звонит сотруднику по ID из его кабинета.
  5. Переключатель «включён» должен показывать «Включено». Сохраните.

5Телефон в браузере

Звонить и принимать звонки можно прямо в CRM, без программы «Софтфон UIS». Телефон живёт в отдельном маленьком окне «Телефон»: оно не закрывается, когда вы переходите между разделами админки, и звонок не обрывается.

Подключение (администратор, один раз на сотрудника)

  1. В кабинете UIS откройте карточку сотрудника и включите «Использовать WebRTC Token».«Сотрудники» → шестерёнка → «Дополнительные настройки». Скопируйте ключ. Галочки «Data API» и «Call API» оператору не включайте: ключ Call API один, он уже стоит в виджете CRM.
  2. Откройте пользователя в CRM: «Пользователи» → нужный менеджер.Внизу страницы — блок «Телефония сотрудника».
  3. Вставьте токен в поле «Токен WebRTC (UIS)» и сохраните.Поле только для записи: после сохранения токен не показывается, рядом написано «сохранён». Пустое поле оставляет сохранённый токен. Убрать токен — галочка «Удалить токен WebRTC».
  4. Проверьте переключатель и виджет.В блоке «Телефония сотрудника» переключатель показывает «Включено», а виджет Новосистем на странице «Интеграции» подключён. Токен снимается по-прежнему галочкой «Удалить токен WebRTC».
  5. Попросите менеджера закрыть программу «Софтфон UIS».Одна линия не работает в двух телефонах сразу: окно ответит «Телефон уже открыт в другом окне или в программе UIS».

Менеджер: начало смены

  1. Нажмите плашку «Телефон» справа внизу любой страницы админки.Откроется окно «Телефон». Если браузер его заблокировал — разрешите всплывающие окна для CRM.
  2. В окне нажмите «Включить телефон» и разрешите микрофон.Статус станет «На линии». Окно сверните, но не закрывайте: входящие приходят туда.
  3. Работайте в CRM как обычно.Плашка «Телефон» остаётся на каждой странице и показывает состояние, а во время звонка — имя и время разговора.
Плашка справа внизуЧто значит

«Включить телефон»Окно открыто, но телефон не запущен: нажмите кнопку в окне
«Подключение…»Телефон соединяется с UIS

6Менеджер звонит клиенту

Сначала карточка клиента, потом звонок из неё. Основной набор — из окна «Телефон» (раздел 5): нужен включённый телефон в браузере и заполненный телефон на сохранённой карточке. Прежний способ, когда UIS сначала звонит вам, работает без браузерного телефона: тогда нужны виджет «Подключён», ID сотрудника UIS и открытый софтфон UIS, в котором вы залогинены.

Сначала карточка и ответственный

  1. Откройте «Клиенты».Если человек уже есть — откройте его карточку и переходите к набору ниже.
  2. Если карточки нет — «Добавить».На этой форме кнопки «Позвонить клиенту» нет. Она появится только после сохранения.
  3. Заполните почту, имя, телефон и компанию.
  4. В блоке «Менеджер» сразу выберите «Ответственный».Начните вводить имя или почту и выберите себя или коллегу, который ведёт клиента. Поле само не заполняется.
  5. Нажмите «Сохранить».Дальше звоните уже с этой карточки.

Из окна «Телефон»

  1. Откройте сохранённую карточку клиента.«Клиенты» → нужный клиент. На форме «Добавить» звонка нет.
  2. Нажмите «Позвонить клиенту» (или значок трубки у поля «Телефон»).Окно «Телефон» само наберёт номер, страница при этом не меняется. Если окно было закрыто, оно откроется: нажмите «Включить телефон», набор продолжится сам.
  3. Говорите.В окне и на плашке — «Идёт дозвон…», потом «Разговор» и время. Кнопки: «Удержать», «Выключить микрофон», «Завершить». Цифры тоновой клавиатуры в окне работают во время разговора.
  4. Закончили — нажмите «Завершить».
Набирается номер из поля «Телефон» на странице. Если вы его поправили и не сохранили, позвонит поправленный. Ссылки tel: в заявках работают так же. Ctrl или ⌘ + клик открывает прежнюю страницу «Позвонить клиенту».

Прежний способ: UIS сначала звонит вам

Так работает кнопка у менеджера без браузерного телефона. Карточка к этому моменту уже сохранена, в блоке «Менеджер» выбран «Ответственный».

  1. Откройте карточку клиента.CRM → Клиенты → нужный клиент.
  2. Нажмите «Позвонить клиенту».
  3. Проверьте номер и подтвердите.Вверху появится «Вызов инициирован: Новосистем соединит вас с …».
  4. Возьмите вызов в приложении UIS.На личный мобильный этот звонок не переводится. Говорите в гарнитуру.
  5. После того как вы ответили, UIS набирает клиента.Пока клиент не взял трубку, вы слышите музыку. Не кладите трубку, пока клиент не ответил.
Пока ждёте клиента, трубку не кладите. Сброс на вашей стороне обрывает набор.

7Входящие: 8 800 и городской 499

Номер 8 800 350-58-98 принимает сценарий «звонок», шаг «Переадресация 1». Звонок сразу идёт на линии Валерии, Александра и Ларисы — в окно «Телефон» или в приложение UIS. Разговор забирает тот, кто ответил первым. Остальным набор прекращается. Личные мобильные в этот дозвон не входят.

  1. Держите окно «Телефон» включённым в рабочее время.В окне и на плашке справа внизу появится «Входящий: …» с именем клиента (если он есть в вашей базе) или с номером, и кнопки «Ответить» и «Отклонить». Если вы всё ещё работаете в программе «Софтфон UIS», держите открытой её: входящий придёт с номера 8 800 350-58-98, имени клиента на экране нет. Если закрыты и окно, и программа, на ваш компьютер звонок не придёт.
  2. Возьмите трубку.Три линии звонят одновременно. Личный мобильный не звонит: запасного перевода на него нет.
  3. Говорите с клиентом как с обычным входящим.Запись разговора остаётся в личном кабинете UIS, в CRM она не скачивается.
  4. После звонка откройте журнал.CRM → Звонки. Строка с ID uis:. Если номер клиента уже есть в базе, карточка подставится сама. Если нет — назначьте клиента на странице звонка и поставьте «следующий контакт», если обещали перезвонить.
Кто первый снял трубку — тот и говорит с клиентом. Очереди «сначала один, потом другой» на этом шаге нет. Михаил в переадресацию не входит.

Прямой звонок на городской номер

Клиент, который звонит лично менеджеру, набирает +7 (499) 995-12-77. UIS просит ввести внутренний номер. Общий вход 8 800 при этом не меняется: он по-прежнему звонит всем троим сразу.

8Журнал звонков

CRM → Звонки — журнал Новосистем. ID записи начинается с uis:.

Клиент находится сам

По цифрам номера: формат не важен (+7, 8, скобки). Неизвестный номер сохраняется без клиента — его можно назначить вручную на странице звонка.

Менеджер

Сначала по employee_id, если он совпадает с «ID сотрудника UIS». Если ID в уведомлении нет — по добавочному.

Повторы не дублируются

UIS может прислать несколько уведомлений по одному звонку. Они обновляют одну строку журнала: состояние, длительность, номера.

10FAQ

Нужна ли теперь программа «Софтфон UIS»? Нет, если у вас включён телефон в браузере. Программу лучше закрыть: линия работает только в одном телефоне. Если токена WebRTC у вас нет, работайте по-старому.
Что будет, если закрыть окно «Телефон»? Телефон выключится, входящие в CRM приходить не будут. Во время разговора браузер спросит подтверждение. Окно можно сворачивать и перетаскивать, переходы по админке ему не мешают.
Можно ли звонить из CRM с телефона или планшета? Окно «Телефон» — только для компьютера. На узком экране плашки нет, работает прежняя кнопка «Позвонить клиенту».
Клиент видит мой номер? Нет. Из окна «Телефон» и из приложения UIS клиент видит +7 (499) 995-12-77. Личный мобильный менеджера на экране клиента не появляется.
Где слушать запись разговора? В ЛК UIS. В карточке звонка CRM пишет, что запись есть в UIS и в CRM не скачивается.
Сменили ключ в UIS — что делать? Вставить новый в «Ключ API» виджета и нажать «Сохранить». Остальные поля трогать не нужно.
