1Как это работает

Новосистем работает на платформе UIS. CRM просит UIS соединить вас с клиентом: сначала звонит ваш телефон, вы берёте трубку, затем UIS набирает клиента. Клиент видит виртуальный номер компании.

NEW Виджет с выключателем

Все настройки Новосистем — в одной карточке на странице «Интеграции». Выключили виджет — CRM перестаёт звонить через UIS и принимать от него события.

NEW Звонок из карточки

Та же кнопка «Позвонить клиенту», что и для Mango. CRM сама выбирает, через кого звонить.

NEW Журнал звонков

UIS присылает уведомления о звонках, CRM пишет их в раздел «Звонки» и находит клиента по цифрам номера.

2Виджет в интеграциях

Настраивает администратор. Менеджеру этот раздел нужен, только чтобы понять, почему звонок не идёт.

  1. Откройте «Настройки сайта» → «Интеграции».Вверху страницы две карточки телефонии: Mango и Новосистем.
  2. В карточке «Новосистем» включите переключатель.Подпись сразу меняется: «Виджет выключен», «Не полностью» или «Виджет включён».
  3. «Ключ API» — постоянный ключ пользователя UIS с доступом к Call API.Как его получить — раздел 3.
  4. «Виртуальный номер» — номер компании в UIS, только цифры, например 74951234567.Его клиент увидит при звонке из CRM.
  5. «Секрет вебхука» — любая длинная случайная строка, которую вы придумали сами.По ней CRM понимает, что уведомление пришло от вашего кабинета UIS.
  6. Нажмите «Сохранить».Под полями появится «URL для ЛК UIS» — он уже содержит ?token= с вашим секретом. Его вставляют в уведомления UIS.
Статус на карточкеЧто значит
«Подключён»Виджет включён, заполнены ключ, виртуальный номер и секрет
«Не полностью»Виджет включён, но какого-то поля не хватает
«Выключен»Галочка снята: звонки через UIS и приём событий отключены
Пустое поле не стирает ключ. Ключ и секрет после сохранения не показываются, в поле написано «сохранён». Чтобы сменить, введите новое значение. Оставили пустым — остаётся старое.

3Настройка личного кабинета UIS

Делается один раз, в кабинете Новосистем (UIS) с правами администратора.

  1. Подключите опции API.«Администратор → Аккаунт → Тариф и опции»: «API Базовый» для уведомлений и «Call API Базовый набор» для звонка из карточки.
  2. Добавьте IP сервера CRM в белый список.«Аккаунт → Правила и настройки безопасности → API». Пока список пуст, UIS отклоняет запросы CRM. IP сервера даёт администратор хостинга.
  3. Выпустите ключ.«Управление пользователями» → пользователь → галочки «Доступ по ключу» и «Доступ к Call API». Ключ показывается один раз — сразу вставьте его в «Ключ API» виджета.
  4. Создайте HTTP-уведомление.«Сервисы и статистика → Уведомления» (в новом кабинете — «Интеграции»). Метод POST, адрес — «URL для ЛК UIS» из виджета целиком, вместе с ?token=….
  5. Добавьте параметры в тело уведомления.Кнопкой «Добавить параметр», имена — ровно как в таблице ниже.
ПараметрЗачем CRM
call_session_idОбязателен. Один звонок — одна строка в журнале, повторы обновляют её
directionВходящий или исходящий (in / out)
contact_phone_numberНомер клиента — по нему находится карточка
virtual_phone_numberНомер компании
employee_idID сотрудника UIS — по нему журнал находит менеджера
extensionДобавочный, если ID в уведомлении нет
start_timeНачало разговора. Без него в журнале окажется время прихода уведомления
talk_durationДлительность разговора в секундах
finish_time, is_lostЗвонок завершён или пропущен
Без call_session_id событие отклоняется. Без верного token или при выключенном виджете — тоже. Журнал отправок в UIS: «Отчёты → Служебные». Если CRM не ответила, UIS повторит отправку через 2, 4, 8 и 16 часов.

4Сотрудник: ID UIS и добавочный

Чтобы кнопка звонка знала, кому звонить первым, у менеджера в CRM должен быть указан его ID сотрудника в UIS.

  1. Узнайте ID сотрудника в ЛК UIS.«Управление пользователями» / «Сотрудники» → карточка сотрудника, числовой идентификатор.
  2. Откройте пользователя в CRM: «Пользователи» → нужный менеджер.Внизу страницы — блок «Телефония сотрудника».
  3. Заполните «ID сотрудника UIS».Только цифры.
  4. «Добавочный» — внутренний номер, если UIS присылает его в уведомлении.Короткий добавочный в звонок из карточки не подставляется: UIS звонит сотруднику по ID из его кабинета.
  5. Галочка «включён» должна стоять. Сохраните.

5Позвонить клиенту

Нужно три вещи: виджет «Подключён», у вас указан ID сотрудника UIS, у клиента заполнен телефон.

  1. Откройте карточку клиента.CRM → Клиенты → нужный клиент.
  2. Нажмите «Позвонить клиенту».
  3. Проверьте номер и подтвердите.
  4. Возьмите трубку.Сначала UIS позвонит вам, потом наберёт клиента. Вверху появится «Вызов инициирован: Новосистем соединит вас с …».

6Журнал звонков

CRM → Звонки — тот же журнал, что и для Mango. Звонки UIS отличаются ID записи: он начинается с uis:.

Клиент находится сам

По цифрам номера: формат не важен (+7, 8, скобки). Неизвестный номер сохраняется без клиента — его можно назначить вручную на странице звонка.

Менеджер

Сначала по employee_id, если он совпадает с «ID сотрудника UIS». Если ID в уведомлении нет — по добавочному.

Повторы не дублируются

UIS может прислать несколько уведомлений по одному звонку. Они обновляют одну строку журнала: состояние, длительность, номера.

8FAQ

ВопросОтвет
Включены и Mango, и Новосистем. Через кого пойдёт звонок? Через Mango, если у вас задан добавочный и виджет Mango настроен. Если добавочного нет, а ID сотрудника UIS заполнен и виджет Новосистем включён — звонок идёт через Новосистем. Журнал принимает события от обоих.
Клиент видит мой номер? Нет, клиент видит виртуальный номер компании из виджета.
Где слушать запись разговора? В ЛК UIS. В карточке звонка CRM пишет, что запись есть в UIS и в CRM не скачивается.
Сменили ключ в UIS — что делать? Вставить новый в «Ключ API» виджета и нажать «Сохранить». Остальные поля трогать не нужно.
