Телефония Mango — звонки прямо из CRM

1Как это работает

Звонок инициирует Mango как обратный вызов: сначала звонит на ваш добавочный, вы поднимаете трубку — и только потом Mango набирает клиента.

NEW Звонок в один клик

Из карточки клиента — без набора номера вручную. Mango сам соединяет ваш добавочный с клиентом.

NEW Журнал звонков

Каждый вызов (входящий и исходящий) падает в раздел «Звонки» с номером, менеджером, клиентом и длительностью.

NEW Записи разговоров

Mango отдаёт запись после завершения — она скачивается в закрытое хранилище и доступна из карточки звонка.

NEW Автопривязка

Клиент находится по цифрам номера (формат не важен: +7, 8, скобки). Звонок попадает в ленту карточки клиента и к последней открытой заявке.

Два способа инициировать вызов. Основной — через API Mango (ключ и соль в виджете Mango: «Настройки сайта» → «Интеграции»). Если у тарифа нет полного API, работает запасной канал «исходящий звонок через вебхук» — для вас разницы нет, кнопка выбирает доступный способ сама.

2Позвонить клиенту

Единственное требование — у клиента заполнен телефон, а у вас задан добавочный (см. раздел 5).

  1. Откройте карточку клиента.CRM → Клиенты → нужный клиент.
  2. Нажмите «Позвонить клиенту».Кнопка в верхнем ряду действий карточки, рядом со «Сменить»/историей.
  3. Проверьте номер и подтвердите.Показаны ваш добавочный и телефон клиента — жмите «Позвонить».
  4. Возьмите трубку.Mango сначала позвонит на ваш добавочный; поднимете — пойдёт вызов клиенту.
Если что-то не настроено — страница не даст отправить вызов и покажет список причин (нет добавочного, нет телефона у клиента, не настроена интеграция). Ошибки уровня «Mango недоступен» приходят сообщением без потери данных.
Клиент видит номер компании, а не ваш добавочный — обратный вызов идёт через линию ВАТС.

3Журнал звонков

CRM → Звонки — все вызовы, которые Mango присылает по вебхуку: входящие, исходящие, пропущенные.

Фильтры и поиск

Справа — фильтры по направлению, состоянию, дате, добавочному. Поиск понимает номер телефона, имя/email клиента и email менеджера.

Звонок без клиента

Неизвестный номер не теряется — звонок хранится в журнале без привязки. Нашли клиента позже — карточку можно назначить вручную на странице звонка.

Звонок в карточке клиента

В карточке клиента есть инлайн «Звонки» — история по этому клиенту. Завершённый разговор дополнительно пишется в ленту активности («Входящий/Исходящий звонок, длительность, добавочный»).

Дедупликация встроена. Mango может прислать событие повторно — по уникальному entry_id и порядковому номеру seq дубли и «откаты» состояния отсекаются, запись в ленте создаётся один раз.

4Записи разговоров

Если в тарифе Mango включена запись — после завершения звонка приходит событие готовности, и файл автоматически скачивается в закрытое хранилище.

  1. Откройте звонок в журнале (или из инлайна в карточке клиента).Поле «Запись разговора».
  2. «Скачать запись» — файл отдаётся как вложение .mp3.Имя файла содержит хвост ID вызова — легко сопоставить.
СтатусЗначение
«Запись есть в Mango, ещё не скачана»Событие пришло, файл в очереди на скачивание — обычно до минуты
«Скачать запись»Файл сохранён у нас, можно слушать
«—»Записи нет (разговора не было или запись выключена в тарифе)
Записи не публичны. Файл лежит вне медиа-каталога сайта; скачать может только менеджер с доступом к карточке этого клиента. Прямая ссылка без прав отдаст отказ.

5Свой добавочный

Менеджер определяется по добавочному: Mango сообщает внутренний номер, CRM находит по нему пользователя. Без добавочного звонок запишется «без менеджера», а кнопка звонка не сработает.

  1. Узнайте свой добавочный в MangoЛК Mango → Сотрудники, либо короткий номер на вашем аппарате/софтфоне.
  2. Откройте свой профиль: Пользователи → ваш пользователь.Или попросите администратора — поле внизу страницы пользователя.
  3. В блоке «Телефония сотрудника» заполните «Добавочный».Только цифры, например 101. Галочка «включён» должна стоять.
  4. Сохраните.Новые звонки с этого добавочного сразу начнут привязываться к вам.

7FAQ

ВопросОтвет
Клиенту показывается мой добавочный? Нет — клиент видит номер компании (линию ВАТС). Добавочный участвует только внутри: Mango звонит на него вам.
Почему сначала звонит мой телефон? Это обратный вызов Mango: сначала соединяется ваша сторона, потом набирается клиент — так платформа гарантирует, что вы на линии.
Входящие тоже видны? Да — все события от ВАТС пишутся в «Звонки» с привязкой к клиенту по номеру и к менеджеру по добавочному.
Звонок привязался к заявке? Автоматически — к последней незавершённой заявке клиента. В заявке видно звонок, в ленте активности — строка с длительностью.
Записи слышат все? Только staff с доступом к карточке клиента. Звонок без клиента в журнале виден всем менеджерам (общий коммутатор), но запись скачает тот, у кого есть права на соответствующую карточку.
Можно ли отправить SMS? В текущем релизе — только звонки. Канал «вебхуки» Mango поддерживает Send_SMS; если нужно — ставим задачу.
