## 3. Архитектура (черновик)

```text
УНФ (регламент ~07:45 ???)
    → файл xlsx/csv (Артикул | Свободно)
    → канал ??? (SFTP / HTTP / …)
Celery Beat 08:00 МСК
    → task pull_and_import_stock
    → download → validate → import_stock_xlsx()
    → archive/ + отчёт; при ошибке → failed/ + notify
```

**Почему сначала файл, не OData:** тот же парсер, что ручная загрузка;
проще согласовать с 1С; проще отладка. OData / HTTP API УНФ — этап 2,
если файл неудобен (отметить здесь, когда решите: ???).

## 5. Задача Celery (черновик)

```text
pull_and_import_stock():
  1. найти/скачать файл за сегодня (контракт §2)
  2. нет файла → WARNING + email, exit
  3. validate_stock_xlsx_upload
  4. import_stock_xlsx (существующий ETL)
  5. сохранить отчёт (updated / ignored / bad_rows / sample unknown)
  6. файл → archive/; ошибка → failed/
```

Логи: без PII; имя файла + counters + примеры неизвестных артикулов.
