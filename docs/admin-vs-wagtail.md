# Django Admin vs Wagtail — для Hoocon CMS

Дата: 2026-07-19.

Официальные опоры: [docs.djangoproject.com](https://docs.djangoproject.com/)
(Admin), [docs.wagtail.org](https://docs.wagtail.org/) (Wagtail).

---

## 1. Разница одной фразой

| | **Django Admin** | **Wagtail** |
|--|------------------|-------------|
| Что это | Встроенная админка Django для CRUD моделей | Отдельная CMS на Django со своим UI |
| Для кого | Разработчик / техничный менеджер | Редактор контента «как в WordPress» |
| Контент | Формы полей модели | Страницы + **StreamField** (блоки) |
| Каталог SKU | Отлично (таблицы, фильтры, импорт) | Хуже: товар — не «страница» |
| Сложность | Уже в Django, ноль лишних систем | +пакет, +модель страниц, обучение |
| API | Сами через DRF | Wagtail API + свои apps |

---

## 2. Когда что выбирать

**Django Admin**, если:

- правите каталог (SKU, атрибуты, PDF) чаще, чем «красивые лендинги»;
- редакторов мало (вы / 1–2 человека), ок табличный UI;
- хотите быстрее MVP на стеке БЗ (как LMS).

**Wagtail**, если:

- много статей/лендингов и нужен удобный блочный редактор;
- нетехнари часто правят вёрстку страниц без разработчика;
- готовы держать две зоны: Wagtail (страницы) + apps (каталог).

Комбо (часто в индустрии): Wagtail для статей + **отдельные** Product-модели
для каталога. Для Hoocon это **этап 2**, не старт.

---

## 3. Рекомендация для Hoocon — **принято**

**v1 и ближайшие этапы: только Django Admin.**

Wagtail **не** подключаем, пока явно не решим иначе (например, поток
нетехнических редакторов статей). Каталог, контент, цены-флаг, RFQ —
через модели + Django Admin (+ при необходимости позже React-admin
для каталога).

**UI-стандарт (2026-07-23):** Django Admin + **django-unfold**, палитра
из brand-токенов проекта (`#dc1313` для Hoocon). Тот же вариант — для
LMS-подобных проектов. Канон: [admin-standard.md](admin-standard.md),
патч в БЗ `docs/kb-patch-django-admin-standard/`.

Почему:

1. Ядро — **каталог и фильтры**, не блочный CMS.
2. Стек БЗ / LMS; быстрее MVP.
3. Цены, флаги, ETL проще в Admin.

---

## 4. Цены (связь с админкой)

Независимо от Admin/Wagtail:

- поле цены у SKU **хранится**;
- `SiteSettings.show_prices_on_site` (или аналог) — по умолчанию `False`;
- API/фронт отдают цену только если флаг включён;
- иначе CTA: «Запросить КП» / цену в письме менеджеру.
