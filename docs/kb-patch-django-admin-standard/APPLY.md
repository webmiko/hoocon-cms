# Как применить патч в главную БЗ

Дата: 2026-07-23.

Канон: `/Users/niko/GitHub/Универсальная-база-знаний`  
Инструкция: `ИНСТРУКЦИЯ-ПО-ОБНОВЛЕНИЮ-БАЗЫ-ЗНАНИЙ.md`

В облачном агенте симлинк `_Универсальная-база-знаний` указывает на
Mac-путь и **не резолвится**. Этот каталог — готовый дифф для ручного
(или локального) переноса в канон.

## Шаги

1. Открыть канон БЗ на машине, где есть репозиторий базы.
2. Скопировать дерево `02-Примеры-кода/django-admin-стандарт/`
   из этого патча в корень БЗ (новые файлы).
3. Влить фрагменты из `patches/`:
   - `AGENTS.md.snippet` → таблица маршрутизации §1;
   - `ВЕБ-СТЕК-README.snippet` → ветка выбора админки;
   - `ИЗМЕНЕНИЯ.md.snippet` → запись журнала.
4. Проверить длину строк ≤ 119, ссылки, отсутствие секретов/цен.
5. Закоммитить в репозитории БЗ (не в `hoocon-cms`).
