# Стиль и цветовая схема админки

Цель: staff UI выглядит как часть продукта, а не «сырой» Django.
Палитра **подбирается под бренд проекта** (Hoocon, LMS, …).

Опора: [Unfold settings / COLORS](https://unfoldadmin.com/docs/configuration/settings/).

---

## 1. Выбранный вариант UI

| Параметр | Значение |
|----------|----------|
| Пакет | `django-unfold` |
| Базовый Theme | **light** (переключатель dark — опционально) |
| Радиус | как у публичного UI проекта (часто `8px`) |
| Шрифт | системный Unfold; не тащить Inter «ради тренда» |
| Логотип | `SITE_LOGO` / `SITE_ICON` из static бренда |
| Акцент | `COLORS.primary` из brand hex |

Не используем как канон: Jazzmin, Grappelli, SimpleUI, голый
`admin/base_site.html` без дизайн-системы (допустим лишь как
временный legacy до миграции на Unfold).

---

## 2. Минимальный `UNFOLD`

```python
# config/settings.py (фрагмент)
from django.templatetags.static import static
from django.urls import reverse_lazy
from django.utils.translation import gettext_lazy as _

from config.brand_colors import PRIMARY_OKLCH  # см. примеры/

UNFOLD = {
    "SITE_TITLE": "Hoocon Admin",
    "SITE_HEADER": "Hoocon",
    "SITE_SUBHEADER": "Каталог и заявки",
    "SITE_URL": "/",
    "THEME": "light",
    "BORDER_RADIUS": "8px",
    "SHOW_HISTORY": True,
    "SHOW_VIEW_ON_SITE": True,
    "COLORS": {
        "primary": PRIMARY_OKLCH,
    },
    "SIDEBAR": {
        "show_search": True,
        "show_all_applications": False,
        "navigation": [
            {
                "title": _("Каталог"),
                "separator": True,
                "items": [
                    {
                        "title": _("SKU"),
                        "icon": "precision_manufacturing",
                        "link": reverse_lazy("admin:catalog_sku_changelist"),
                    },
                ],
            },
        ],
    },
}
```

`INSTALLED_APPS`: `unfold` (и нужные `unfold.contrib.*`) **строго до**
`django.contrib.admin`.

## 3. Подбор цвета под проект

### 3.1 Входные данные

Из дизайн-токенов / прототипа публичного сайта взять:

| Токен | Пример Hoocon | Пример LMS |
|-------|---------------|------------|
| Brand / primary | `#dc1313` | фирменный акцент курса/бренда |
| Текст | `#333` / `#555` | контрастный тёмный |
| Фон страницы | `#f2f2f2` | нейтральный светлый |
| Радиус | `8px` | согласовать с UI |

### 3.2 Правила

1. **Primary 500** ≈ основной brand hex (кнопки, ссылки, акцент).
2. Шкала 50…950 — один hue, меняются lightness/chroma (OKLCH).
3. Контраст текста на primary-кнопках — WCAG AA (часто белый на 600+).
4. Не оставлять дефолтный фиолетовый Unfold, если бренд другой.
5. Neutral `base` можно не трогать, пока бренд не задаёт «холод/тепло»
   серого; при необходимости сдвинуть hue `base` к бренду (±).
6. Dark theme: не делать default для industrial B2B / LMS-кабинета,
   пока заказчик не просит.

### 3.3 Рецепт hex → OKLCH-шкала

1. Конвертировать brand hex → OKLCH (L C H).
2. Зафиксировать **H** (hue) и построить оттенки:
   - 50–200: высокий L, низкий C;
   - 500–600: brand / hover;
   - 800–950: низкий L для текста на светлом.
3. Проверить кнопки и focus ring в light.
4. Записать словарь в `brand_colors.py` (или settings) — **без**
   магических значений вразброс по templates.

Фрагмент-хелпер: [примеры/brand_colors.py](примеры/brand_colors.py).

### 3.4 Быстрая таблица для Hoocon

Brand `#dc1313` → красный hue (~25–40 в OKLCH, уточнить конвертером).
`BORDER_RADIUS = "8px"` как в публичных токенах.
`SITE_HEADER = "Hoocon"`, лого из static.

Для LMS — та же процедура, другие hex и `SITE_HEADER`.

## 4. Типографика и плотность

- Changelist: компактные строки, `list_per_page` 25–50.
- Формы: fieldsets с короткими заголовками на русском (или i18n).
- Без emoji в навигации (иконки Material через Unfold `icon=`).
- Без glassmorphism / neon glow / purple gradients.

---

## 5. Брендинг login

`UNFOLD["LOGIN"]`:

- опциональный фон (`image`) — продукт/атмосфера, не стоковый stock;
- `redirect_after` → главный changelist домена (заявки или SKU).

Не размещать на login промо-бейджи и маркетинговый шум.

---

## 6. Согласованность с публичным фронтом

| Слой | Источник правды |
|------|-----------------|
| Публичный React | `tokens.css` / прототип |
| Admin Unfold | `UNFOLD["COLORS"]` + `BORDER_RADIUS` |
| Связь | один brand hex → оба слоя |

Расхождение primary между сайтом и Admin = дефект бренда; чинить
в токенах, не «почти тот же красный».

---

## 7. Миграция с legacy Admin

1. Добавить Unfold, сохранить URL `/admin/`.
2. Перевести ModelAdmin на `unfold.admin.ModelAdmin` пакетами apps.
3. Подключить COLORS из бренда.
4. Удалить одноразовые `templates/admin/base_site.html`, если дублируют
   SITE_HEADER/LOGO.
5. Регрессия: login, list, filter, upload файла, permissions.
