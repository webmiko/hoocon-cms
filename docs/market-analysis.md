Дата: 2026-07-19  
Источники: живой [hoocon.ru](https://hoocon.ru) (проверка 2026-07-19);
аудит `../hoocon/docs/АУДИТ_HOOCON_RU.md`; конверсии
`../hoocon/docs/КОНВЕРСИЯ_HOOCON_СВОДКА.md`; референсы
`../hoocon/docs/прототипы/РЕФЕРЕНСЫ_OVK_B2B.md`; официальные сайты
Belimo / Dastech / дилеры (Panoramavent и др.).  
Опора БЗ: `ВЕБ-РАЗРАБОТКА-Кастомный-стек/` (SEO SPA, CWV, WCAG);

Инфра prod (зафиксировано): **VPS + домен на reg.ru**, почта —
**Яндекс 360** (~1 год) — см. [infra-reg-ru.md](infra-reg-ru.md).

## 0. Вердикт (для плана)

Клиент B2B (инженер / снабженец / дилер) приходит не «купить в корзину»,
а **подобрать модель, скачать документ, убедиться в замене и получить КП**.

Сейчас hoocon.ru уже сдвинулся к RFQ («Запрос КП»), но платформа Tilda
держит: слабые фильтры, нестабильный SEO-каталог, e-com иконки без цены,
низкую конверсию форм (~0,09% сессий → заявка за год по Tilda).

Чтобы быть **ближе к клиенту и лучше конкурентов-дилеров**, CMS должна
закрыть боли подбора и доверия; чтобы быть **лучше западных OEM по удобству
в РФ** — скорость ответа, склад Москва, таблицы аналогов, понятный RFQ
без корзины.

Sitemap: **~36 URL** (`/catalog`, `/company`, `/statyi`, `/news`,
SKU-страницы `privod-…`, `/gde-kupit`, юр. страницы). Каталог —
`/catalog` (не `/katalog` — последний даёт 404).

### 1.2 Каталог `/catalog`

- H1 «Каталог продукции Hoocon» есть.
- В доступном DOM на момент проверки **почти нет списка SKU**
  (контент Store, похоже, тянется JS) — риск для индексации и CWV
  (БЗ: SEO SPA — контент каталога нужен в исходном HTML / гибриде).
- Фильтры Tilda Store (из API-выгрузки `hoocon_catalog_api.json`)
  заложены по «Назначению» и вложенным сериям, но UX фильтров
  инженера (момент / 24|230 / сигнал / пружина) на витрине слабый.

### 1.3 Сильные стороны (сохранить в CMS)

1. ЧПУ SKU на транслите (`/privod-vozdushniy-hva-5nm` и т.д.).
2. Переход к **RFQ** вместо «купить вслепую».
3. FAQ с реальной инженерной ценностью (SA vs DA — нельзя путать).
4. Линейки: воздух / пружина / противопожар / дымоудаление / краны.
5. Упор на склад и доставку по РФ в title/оффере.

### 1.4 Боли текущего сайта (приоритизация)

| # | Боль клиента | Симптом на сайте | Влияние |
|---|--------------|------------------|---------|
| B1 | «Нужен аналог Belimo / замена» | Нет единой таблицы аналогов | Потеря лида дилеру с таблицами |
| B2 | «Отфильтровать 5 Нм / 230 В / пружина» | Нет нормальных фасет-фильтров | Уход в каталог конкурента |
| B3 | «Скачать паспорт / сертификат» | PDF не first-class | Недоверие инженера/ПБ |
| B4 | «Понятно ли, что будет после заявки» | «Запрос КП» без SLA ответа | Брошенные формы |
| B5 | «Можно ли верить бренду в РФ» | Мало кейсов РФ, шум CN-контактов | Слабый E-E-A-T |
| B6 | Навигация и скорость | Бургер на desktop; Tilda JS | Трение + SEO |
| B7 | Смешанные сигналы e-com | Cart / Wishlist без цены и checkout | Раздражение / отказы |
| B8 | Конверсия | ~**0,09%** заявок от сессий Tilda (год) | Бизнес-боль |

Аудит апреля и живой срез июля согласованы: title главной починен;
корневые UX/CRO-проблемы (бургер, доверие, фильтры, аналоги) — нет.

## 3. Рынок: что взять у конкурентов

### 3.1 Зарубежные OEM

#### Belimo ([belimo.com](https://www.belimo.com/))

Взять (паттерн, не копировать UI/тексты):

- дерево продуктов + **Download / Support**;
- инструменты **SelectPro** (подбор) и **RetroFIT+** (замена) —
  у Hoocon → упрощённый «подбор по моменту/площади» + форма замены;
- атрибуты в таблице; аксессуары; версия документа;
- CTA contact / quote / where to buy.

Не брать в v1: полноценный webshop, IoT-маркетинг, desktop-приложение.

#### Danfoss / Siemens / Johnson Controls (из РЕФЕРЕНСЫ_OVK_B2B)

- двухуровневая шапка (контакты сверху, меню+поиск ниже);
- вход по **категориям применения**, не только по SKU;
- плотный футер с сегментами;
- «Resources» полоса (сертификаты, подбор, партнёры).

### 3.2 Россия: бренды и дилеры

#### Dastech ([dastech.ru](https://dastech.ru/))

Взять:

- вход по **сериям применения** (FR/FS/AR/DA ≈ ПБ / дым / воздух);
- скачиваемые **каталоги PDF** и сертификаты одной кнопкой;
- доверие через **именованные объекты РФ** (ПИК, РЖД, ЦОД…) —
  у Hoocon сейчас слабее; нужно свои кейсы/объекты РФ.

#### Дилеры (gs-ing, Panoramavent, privods.com и аналоги)

Взять:

- **таблицы аналогов Belimo → бренд** (Panoramavent уже включает Hoocon
  в карту аналогов — клиент находит бренд у дилера раньше, чем на OEM);
- фильтры момент / напряжение / пружина;
- иногда **открытые цены** (даёт конверсию дилеру).

Стратегия Hoocon: не проигрывать дилеру по удобству подбора; цены —
по флагу (уже в плане: в БД есть, на сайте скрыты по умолчанию).

## 4. Как быть лучше и ближе к клиенту

### 4.1 Дифференциация vs дилер

1. **Первичный источник правды** по SKU Hoocon (атрибуты, файлы, новости
   цен) — дилер копирует; OEM должен быть удобнее.
2. **Инженерный FAQ и статьи** с перелинковкой на SKU (уже зачаток).
3. **RFQ с контекстом SKU** (модель, кол-во, объект) + Celery-письмо
   на `sales@hoocon.ru` через SMTP Яндекс 360.
4. **SLA в UI**: «Ответим в рабочее время за N часов».
5. **Склад Москва** как жёсткий оффер в hero и карточке (наличие —
   позже; в v1 хотя бы текст/флаг).

### 4.2 Дифференциация vs Belimo (реалистично)

Не конкурировать брендом 50 лет — конкурировать **доступностью в РФ**:
цена/аналог, срок, русскоязычный подбор, живой менеджер, OEM.

### 4.3 Целевые исходы продукта (связь с MVP)

| Исход | Метрика (после запуска) | Фича CMS |
|-------|-------------------------|----------|
| Быстрый подбор | время до карточки; % с фильтрами | catalog filters |
| Документы | скачивания PDF / лид | ProductFile |
| Заявка | CVR визит→Lead ≫ 0,09% | leads + антиспам |
| SEO | индексируемые `/catalog`, SKU | гибрид head + HTML |
| Доверие | клики сертификаты/кейсы | content + media |

Пороги CWV/a11y — из БЗ (`CWV-WCAG-и-чеклисты.md`): LCP &lt; 2 s,
INP &lt; 200 ms, CLS &lt; 0.08, WCAG 2.2 AA.
