# Технический стиль копирайта (канон Belimo RU)

Дата: 2026-07-19  
Назначение: **единый образец** перевода и терминологии для паспортов,
инструкций, ТТХ на сайте Hoocon. Источник стиля — русская терминология
Belimo (B2B HVAC).

Для ИИ и редакторов: при любом новом/правке технического текста
(описание SKU, specs, инструкция категории, PDF-выписки) **сверяйся с
этим файлом**. UI-лейблы фасетов могут быть короче («Напряжение»), но
значения и фразы в теле — по таблицам ниже.

## Правила стиля (кратко)

1. **Управление (фасет / EAV):** три значения — «Открыто/закрыто»,
   «2-/3-позиционное», «Пропорциональное». В прозе можно писать
   «пропорциональное (модулирующее)» и «вкл./выкл. (ON/OFF)»; не оставлять
   голое `ON/OFF` / `Modulating` в русском абзаце.
2. **Сигналы:** писать **`В=`** для постоянного напряжения
   (`0(2)…10 В=`), ток — **`мА`** (`0(4)…20 мА`). Не `VDC` / `mA` в
   русском ТТХ. Режим **0(4)…20 мА — только спецзаказ** (заводская
   установка — напряжение); в UI канон:
   `0(2)...10 В= / 0(4)...20 мА (спецзаказ)`, ссылка FAQ
   `/faq#signal-ma-special-order`.
3. **Защита:**
   - *Класс защиты* — только III / II (безопасное сверхнизкое
     напряжение / полная изоляция);
   - *Степень защиты корпуса* — IP54, IP44 и т.п.  
   Не писать «Класс защиты IP54».
4. **Момент:** «крутящий момент», единица **Нм** (не «Н·м» в UI без
   нужды).
5. **Гарантия (РФ):** канон **24 месяца** — константы в
   `backend/config/warranty.py` (`WARRANTY_MONTHS`). Не писать «3 года».
6. **Буква ё:** в русском тексте сайта **не заменять ё на е**. Пиши ещё,
   объём, партнёр, надёжный, расчёт, счёт, учёт, приём, трёх, чертёж
   (ед.ч.; мн.ч. «чертежи» — без ё), даёт, идёт… Не путать **все** (all)
   и **всё** (everything). Cursor: `.cursor/rules/russian-yo.mdc`.
7. **Переключатели:** «вспомогательный переключатель»; исполнения
   DS/AS — «включает N групп(у) вспомогательных переключателей». В
   заголовке SKU: без «Нет»; при наличии — `SPDT-1` / `SPDT-2`
   (фасет каталога: Нет / SPDT-1 / SPDT-2; см. `normalize_aux_switch_value`).
8. **Пробелы и единицы:** `24 В`, `50/60 Гц`, `мм²`, `м²`, `°C`,
   диапазоны с многоточием `…` или en-dash `–`.
9. **Объект:** «электропривод воздушной заслонки» / «привод заслонки»;
   область — «системы HVAC (отопления, вентиляции и кондиционирования)»
   или коротко «ОВК», если уже введено.
10. **Предупреждения:** тон официальный («запрещается», «вскрытие
    корпуса разрешено только производителю»).
