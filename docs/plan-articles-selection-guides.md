## 2. Приоритет 1 — структура и проверенные факты

Ниже — только то, что **подтверждено документами/кодом репозитория**  
или явно помечено как *ориентир / требует сверки с паспортом заслонки*.

### P1-1. Подбор по площади и давлению

**Структура**

1. Hero: зачем момент; ссылка на каталог и FAQ.  
2. Что нужно от проекта (S или D, P, тип заслонки, запас).  
3. Две рабочие формулы-ориентира (с оговоркой).  
4. Пример расчёта (из статьи «Применение»).  
5. Куда идти в каталоге (фильтр по Нм).  
6. Когда считать нельзя «с потолка» (ОЗК → SA, таблицы OEM заслонки).

**Проверенные факты**

| Факт | Источник |
|------|----------|
| Площадь круга: S = π r²; пример Ø 0,2 м → ≈ 0,0314 м² | FAQ `/faq` |
| Ориентир момента (FAQ): M ≈ (D³ × P × k) / C; k≈0,5…3; C≈2000…4000 | FAQ |
| Ориентир (статья применение): Mтреб = S × P × Kтип × Kзапас; Kтип 1,0 / 1,4 / 1,8; Kзапас ≈ 1,3 | fixture применение |
| Пример: 0,96 м² × 450 Па × 1,4 × 1,3 ≈ 7,9 Нм → ряд **10 Нм** | то же |
| Единица момента — **Нм** | tech-copy |
| При P > 1000 Па — увеличивать запас (ориентир до ~40 %) | статья применение |
| SA ≠ DA на ОЗК | FAQ |

**Разрыв формул:** FAQ и «Применение» дают **разные** эмпирические модели.  
В статье P1-1 зафиксировать **одну** (предпочтительно S×P×Kтип×Kзапас — нагляднее для прямоугольных)  
и второй дать как «альтернативный ориентир из FAQ», с дисклеймером:  
*истина — таблица производителя заслонки + паспорт привода*.

**Не утверждать:** универсальную таблицу «м² → Нм» без давления и типа створки.

### P1-3. 24 В или 230 В

**Структура**

1. Два канонических номинала в каталоге.  
2. Класс защиты III vs II (не путать с IP).  
3. Типовые сценарии: АСУ/щит 24 В vs силовой щит 230 В.  
4. Что смотреть в карточке (фасет «Напряжение»).  
5. Ошибки: «подойдёт любой», путаница класса защиты и IP.

**Проверенные факты**

| Факт | Источник |
|------|----------|
| AC/DC **24 В**, 50/60 Гц | tech-copy |
| AC **100…240 В**, 50/60 Гц (в быту часто «230 В») | tech-copy |
| Класс защиты **III** (БСНН) / **II** (полная изоляция) ≠ IP | tech-copy §3 |
| Степень защиты корпуса — отдельно (напр. IP54) | tech-copy |
| Фасет каталога `voltage` | facets/defs.py |
| Пикер изданий часто 24/230 на одной Nm-линейке | series-card-templates |

**Не утверждать:** нормативы ПУЭ «должен быть только 24» без ссылки на проект;  
статья — про согласование с существующим щитом/контроллером.

### P1-4. Типы управления

**Структура**

1. Три значения фасета (таблица).  
2. Суффиксы D / A (и 2-/3 в прозе).  
3. Сигнал Y `0(2)…10 В=`; ток — спецзаказ.  
4. Когда что выбирать (заслонка on/off, ОЗК, регулировка расхода).  
5. Ссылки FAQ мА + каталог фильтр «Управление».

**Проверенные факты**

| Факт | Источник |
|------|----------|
| Фасет: Открыто/закрыто · 2-/3-позиционное · Пропорциональное | tech-copy |
| Пропорциональное = модулирующее; не «плавное» | tech-copy |
| Заводская уставка пропорциональных: **0(2)…10 В=** (часто 0…10 В=) | FAQ `#signal-ma-special-order` |
| **0(4)…20 мА** — только спецзаказ (DIP / завод) | FAQ |
| D ≈ Открыто/закрыто; A ≈ пропорциональное; S — вспом. переключатель | спецификация модельного ряда |
| ОЗК SA FU: управление обычно Открыто/закрыто + пружина | спецификация |

### P1-5. MU vs MQU vs HV (скорость)

**Структура**

1. Задача: время хода vs аварийный возврат (не путать с FU).  
2. Таблица ориентиров времени из спецификации.  
3. Когда MU достаточно; когда MQU/HV.  
4. Ссылки на категории каталога.  
5. Напоминание: ускоренный ход ≠ fail-safe.

**Проверенные факты**

| Факт | Источник |
|------|----------|
| MU: типовые времена хода десятки–сотни с (напр. DA2 &lt;30 с … DA24 &lt;160 с) | спецификация |
| MQU: ≈ 8 с / ≈ 16 с при 8 / 16 Нм; без пружины | спецификация |
| HV …Q: ориентир 5 Нм ≈ 2,5 с; 8 Нм ≈ 4 с; 20 Нм ≈ 7 с; BLDC | статья компании + спецификация dash |
| MQU — «ускоренный без пружинного возврата» | series / ETL DAMQU copy |
| Категории: `elektroprivody-vozdushnye-bez-pruzhinnogo-vozvrata`, `…-uskorennye-…` | series_categories.py |
| Fail-safe — отдельная ось (FU/EU / …F/…E) | FAQ + спецификация |

**Не утверждать:** точные секунды без оговорки «ориентир; паспорт SKU».

## 4. Риски и открытые вопросы

1. **Свести формулы момента** (FAQ vs применение) до одного канона в FAQ + P1-1.  
2. **Belimo-кроссы:** нужна выгрузка/валидация или статья остаётся «метод + форма».  
3. **HV в каталоге:** уточнить, все ли SKU HV в отдельной категории или в «без пружины» — ссылки в P1-5 строить по факту витрины.  
4. Кейсы РФ (P3) — только после подтверждения маркетингом/ПТО.
