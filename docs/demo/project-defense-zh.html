现在 vs 新项目

一眼看懂：关掉哪些问题，换来哪些能力。

hoocon.ru · Tilda

  • 有购物车 / 收藏，却无价格与下单
  • 筛选弱，工程师不好找型号
  • Store 目录靠 JS —— SEO 风险
  • 不能方便对比几款产品
  • 询价后难系统跟进
  • 功能受建站平台限制

Hoocon CMS

  • 只做询价 —— B2B 语言，不是电商
  • 筛选：扭矩、电压、弹簧
  • 可收录的 SKU + 从 Tilda 做 301
  • 按参数对比型号
  • 线索进后台 + 通知销售
  • 自有 VPS、ETL、持续迭代

结论：CMS 是销售工具，不是「换皮设计」
