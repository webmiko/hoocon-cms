# Квиз подбора: аналоги при отсутствии на складе

## Сделано (v2.6)

Ветка **«Комплект кран + привод»** (`need=kit`):

1. Первичный поиск в категории `komplekty` (H81 / H8205).
2. Если подходящих комплектов **нет в наличии** (или нет совпадений после relax) —
   fallback через `GET /api/catalog/quiz-analogs/?need=kit`.
3. Подбор **отдельных позиций**: шаровой кран (DN/Kvs/ways) + совместимый
   привод из EAV «Совместимый привод» + кронштейн BR-M / BR-ML / BR-H.
4. Суффикс привода из ответов квиза: напряжение → семейство DA, управление +
   aux → `-D` / `-DS` / `-A` / `-AS`.

Код: `backend/catalog/quiz_analogs.py`, `useQuizResults.ts`, `QuizKitAnalogCard`.

## План расширения

| Приоритет | Сценарий | Идея реализации |
|-----------|----------|-----------------|
| P1 | **Привод** — нет нужного Nm в наличии | Ближайшая ступень лестницы Nm в той же
  категории; при полном отсутствии — relax moment с пометкой в UI |
| P1 | **Шаровой кран** — есть кран, пользователь мог бы взять комплект | Если
  для DN/Kvs есть H81 в наличии — CTA «Готовый комплект» рядом с краном |
| P2 | **Belimo → Hoocon** в квизе | Поле артикула или шаг «замена Belimo»;
  `belimo_codes_for_sku` / facet `analog`; ссылка на `/replacement` |
| P2 | **Кронштейн** (`need=adapter`) — нет BR-M/BR-ML в наличии | Аналог:
  совместимый кран + привод из `compatible_positions` |
| P3 | **Сквозной комплект** actuator + ball_valve | Два прохода квиза или
  объединённый результат «кран + привод + кронштейн» без ветки kit |
| P3 | **Приоритет наличия** во всех ветках | `in_stock=1` в primary fetch +
  сортировка; analog только как второй ярус |

## Инварианты (не ломать)

- Intent-фильтры квиза (control, voltage, q для smoke) не смягчать в analog.
- Совместимость кран ↔ привод — только из EAV / `ball_valve_kit`, не угадывать.
- Регресс-тест на loaded surface: API + `useQuizResults` + карточка в `#podbor`.

## Связанные файлы

- `backend/catalog/ball_valve_kit.py` — RFQ kit на PDP (тот же контракт семейств).
- `backend/catalog/compatible_positions.py` — кронштейн ↔ привод ↔ кран.
- `quizToCatalog.ts` — маппинг ответов.
