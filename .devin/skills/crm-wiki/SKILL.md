# Вики: руководство CRM 3.0

Прочитай и применяй канон: `.cursor/rules/wiki-crm-guide.mdc`.

Ключевое:

- Канон — `backend/content/fixtures/wiki/admin-3-0-manager-guide.html`
  (сид `seed_wiki`); телефония — `novosystem-telephony-guide.html`.
- При изменении функций для менеджера: строка в начало таблицы
  `#changelog` (дата, что изменено, как работать), при нужде — подраздел
  + пункт оглавления, при смене смысла страницы — `summary` в
  `seed_wiki.py`. Старые строки журнала не удалять.
- Не обновлять из-за рефакторинга, тестов, вёрстки без нового смысла.
- Русский с ё; только то, что есть в продукте; версию из-за правки
  руководства не поднимать.
- Проверка — узкий тест в `backend/tests/test_wiki_admin.py`.
