# Виджеты админки: отдельно и с выключателем

Прочитай и применяй канон: `.cursor/rules/admin-widgets.mdc`.

Ключевое:

1. Свой модуль, поля настроек, шаблон, обработчик сохранения и тесты —
   соседний виджет их не импортирует; страница списка только обходит
   реестр, без `if` второго провайдера внутри первого.
2. Выключатель: выкл — нет карточки действия, кнопки молчат, входящий
   адрес не принимает события.
3. Снятие: убрать из реестра и удалить модуль; имя снятого виджета не
   должно оставаться в подписях админки, ошибках для менеджера и вики.
4. Рабочая телефония — Новосистем; старой АТС в админке нет.
